Tutorial para iniciantes

Executar o Gamma Exposure no seu computador

Você não precisa saber compilar programas nem usar Git. A forma recomendada no Windows é: instalar Python uma vez, baixar o ZIP, extrair a pasta e dar duplo clique em um arquivo .bat.

Antes de começar

O que significa “executar localmente”?

O dashboard continua abrindo no navegador, mas os arquivos são servidos pelo próprio computador. O endereço será parecido com http://127.0.0.1:8000. Esse endereço não publica o sistema na internet.

O projeto atual também não precisa de Node.js, npm ou compilação frontend. A interface é HTML/CSS/JavaScript e o Python fornece apenas o pequeno servidor local e, quando solicitado, os coletores.

1

Instale Python

Abra o PowerShell e execute winget install -e --id Python.Python.3.12. Depois feche e reabra o PowerShell.

2

Baixe e extraia

No GitHub, use Code → Download ZIP. Depois clique com o botão direito no ZIP e escolha Extrair Tudo.

3

Dê duplo clique

Na pasta extraída, abra Executar-Gamma-Exposure.bat e escolha a opção desejada.

Menu do Windows

Duas formas de abrir

1 · Abrir com dados salvos

É o modo mais rápido. Não instala bibliotecas extras e usa os JSON que já vieram no projeto. É útil para estudar o sistema mesmo sem atualizar a cadeia.

2 · Atualizar dados e abrir

Cria automaticamente o ambiente .venv-local, instala as bibliotecas necessárias e tenta atualizar CBOE, EWZ e WIN antes de abrir.

Python pelo WinGet

Instalação passo a passo

  1. Pressione a tecla Windows e procure por PowerShell.
  2. Abra o PowerShell.
  3. Digite python --version.
  4. Se Python 3 já aparecer, não é necessário instalar novamente.
  5. Se não aparecer, execute winget install -e --id Python.Python.3.12.
  6. Quando terminar, feche o PowerShell e abra de novo.
  7. Confirme com python --version ou py -3 --version.

Durante o uso

Por que aparece uma janela preta?

Essa janela é o servidor local. Não a feche enquanto estiver usando o dashboard. O navegador pode ser fechado e aberto novamente, mas o servidor deve continuar ativo.

Para encerrar corretamente, volte à janela e pressione Ctrl + C.

Se o navegador não abrir

Copie o endereço mostrado na janela

Normalmente será http://127.0.0.1:8000/. Se a porta 8000 já estiver ocupada, o programa procura automaticamente 8001, 8002 e assim por diante.

Primeira atualização

O que é a pasta .venv-local?

É um ambiente Python isolado usado apenas pelo Gamma Exposure. Ele evita misturar as bibliotecas do projeto com outros programas instalados no computador. Você não precisa abrir essa pasta nem editar nada nela.

Se ela for apagada, a opção “Atualizar dados e abrir” simplesmente a cria novamente.

Problemas comuns

Soluções rápidas

“Python não foi encontrado”

Instale pelo WinGet e reabra o terminal. Teste python --version e py -3 --version.

Atualização falhou

Verifique a internet. Você ainda pode usar a opção 1 e abrir com os últimos dados já salvos.

Porta 8000 ocupada

Não precisa alterar configuração: o programa procura outra porta livre automaticamente e mostra o endereço correto.

Windows mostrou um aviso

Confirme que o ZIP veio do repositório oficial. O servidor usa apenas 127.0.0.1, isto é, o próprio computador.

Usuários avançados

Comandos manuais

Abrir sem atualizar:

python local_app.py

Instalar dependências e atualizar antes de abrir:

python -m pip install -r collector\requirements.txt
python local_app.py --update-data

Não abrir o navegador automaticamente:

python local_app.py --no-browser

Importante

Rodar localmente não muda a natureza dos dados

A chain pública do CBOE e o feed público usado nos candles continuam sujeitos a atraso e indisponibilidade. Rodar no seu computador muda onde a interface é servida; não transforma as fontes em feeds profissionais real-time.
